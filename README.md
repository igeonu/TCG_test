# Rune Duel (룬 결투)

포커 족보 덱 빌딩 & 1v1 HP 전투 카드 게임.

- `game/` : **게임 본편** — 라이브 서비스형 구조(하단 탭 · 모달 · 세로 탭 · 3분할 덱 편집기) + 레트로 CRT 포커 테이블 디자인
- `rune-duel-ui/` : 기획 단계의 UI/UX 시안 5종(A~E) — 참고용으로 보관
- `serve.py` : 캐시를 끈 개발용 웹 서버 (VS Code F5가 사용)

## VS Code에서 실행하기

이 폴더를 VS Code로 엽니다. (**파일 → 폴더 열기**)

### 방법 1: F5 (추천)
1. 왼쪽 **실행 및 디버그** 탭에서 `Rune Duel 열기 (Edge)` 또는 `(Chrome)`을 선택합니다.
2. **F5**를 누르면 `serve.py`(포트 5173)가 켜지고 `game/`이 브라우저에서 열립니다.
3. 끝낼 때는 터미널 패널의 서버 작업을 휴지통 아이콘으로 종료합니다.

Python 3이 설치되어 있어야 합니다. 터미널에서 직접 켤 수도 있습니다.

```powershell
python serve.py
```

`serve.py`는 브라우저 캐시를 끄므로, 코드를 고친 뒤 새로고침만 해도 바로 반영됩니다.

### 방법 2: Live Server 확장
추천 확장 **Live Server**를 설치한 뒤 오른쪽 아래 **Go Live**를 누르면 `http://localhost:5500`에서 열립니다. 수정 사항이 안 보이면 **Ctrl+F5**로 새로고침하세요.

### 방법 3: 그냥 열기
`game/index.html`을 더블클릭해도 동작합니다. (웹 폰트 때문에 인터넷 연결 필요)

## 주요 기능

- **전투**: 포커 카드 7장 중 5장으로 족보를 만들고, 점수 차이만큼 상대 HP를 깎습니다. 점수가 같으면 높은 숫자 → 키커 순으로 비교합니다.
- **족보 가이드**: 전투 화면 왼쪽 **족보 점수표**에 마우스를 올리면 예시 카드가 보이고, **? 예시 보기**(또는 `H` 키)로 10가지 족보의 예시·만드는 법을 볼 수 있습니다. 패 구성 단계에서는 "1장만 더 오면 플러시" 같은 힌트가 나옵니다.
- **AI 난이도**: 쉬움 · 보통 · 어려움 3단계. 연습 모드의 AI 덱은 난이도에 적힌 성향대로 만들어집니다.
  - 쉬움 (하트 방어형): 패를 무작위로 고를 때가 있음, 액티브 사용이 무작위
  - 보통 (스페이드 공격형): 리롤로 족보를 키우고, 상황을 보고 카드를 씀 (80%)
  - 어려움 (전설 2장 풀덱): 높은 등급 우선 드래프트, 항상 상황 판단
- **연출·사운드**: 피해량에 따른 타격음과 히트스톱, 영웅·전설 카드 획득/사용 연출, 배경음악. 헤더의 🔊 버튼으로 음소거합니다.
- **설정**: 연출 속도, 효과음·배경음악 볼륨, 화면 흔들림, 섬광·깜빡임 줄이기, 기록/덱 초기화(각각 확인 후).

### 현재 규칙 메모
- **특성 기능과 캐릭터 기능은 제외**한 상태입니다.
- 무작위·친구 대전은 아직 온라인이 아니며 AI가 상대합니다.
- 카드 밸런스 (데모 값):
  - 강타: 족보 점수의 25%만큼 피해 추가 (최소 +3)
  - 일격: 치명타 확률 +30% (치명타 시 점수 ×1.5)
  - 심판: 최종 데미지 ×1.6, 쿨타임 3턴
  - 조커: 매 턴 리롤 +1, 원 페어 이상이면 족보 점수의 20%만큼 피해 추가
- 덱·대전 기록·설정은 브라우저에 저장됩니다.

## 배포 (GitHub Pages)

`game/index.html`이 불러오는 JS·CSS 주소에는 `?v=숫자`가 붙어 있습니다. 배포할 때 이 숫자를 한 번에 올려야 방문자의 브라우저가 이전 파일을 다시 쓰지 않습니다.

```powershell
(Get-Content game/index.html) -replace '\?v=\d+', "?v=$(Get-Date -Format yyMMddHHmm)" | Set-Content -Encoding utf8 game/index.html
```
