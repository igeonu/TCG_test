# Rune Duel (룬 결투)

포커 족보 덱 빌딩 & 1v1 HP 전투 카드 게임.

- `game/` : **게임 본편** — 라이브 서비스형 구조(하단 탭 · 모달 · 세로 탭 · 3분할 덱 편집기) + 레트로 CRT 포커 테이블 디자인
- `rune-duel-ui/` : 기획 단계의 UI/UX 시안 5종(A~E) — 참고용으로 보관

## VS Code에서 실행하기

이 폴더를 VS Code로 엽니다. (**파일 → 폴더 열기**)

### 방법 1: F5 (추천)
1. 왼쪽 **실행 및 디버그** 탭에서 `Rune Duel 열기 (Edge)` 또는 `(Chrome)`을 선택합니다.
2. **F5**를 누르면 Python 웹 서버(포트 5173)가 켜지고 `game/`이 브라우저에서 열립니다.
3. 끝낼 때는 터미널 패널의 서버 작업을 휴지통 아이콘으로 종료합니다.

Python이 설치되어 있어야 합니다.

### 방법 2: Live Server 확장
추천 확장 **Live Server**를 설치한 뒤 오른쪽 아래 **Go Live**를 누르면 `http://localhost:5500`에서 열립니다.

### 방법 3: 그냥 열기
`game/index.html`을 더블클릭해도 동작합니다. (웹 폰트 때문에 인터넷 연결 필요)

## 게임 구성 (`game/`)

| 파일 | 내용 |
|---|---|
| `js/data.js` | 효과 카드 52장, 덱 규칙(26장 · 영웅 6 · 전설 2), AI 난이도 3단계, 예시 기록 |
| `js/app.js` | 화면 전환, 헤더·하단 탭, CRT 효과, 모달·토스트·설정, 저장(브라우저 localStorage) |
| `js/lobby.js` | 홈, 무작위 매칭, 친구와 경기, AI 연습, 카드 살펴보기, 나만의 덱, 대전 기록 |
| `js/battle.js` | 전장: 드래프트 → 전투 패 구성 → 쇼다운 준비 → 피해 정산 |
| `js/result.js` | 승리/패배 연출, 명예의 전당, 카드별 활약 기록 |
| `css/style.css` | 레트로 CRT 포커 테이블 디자인 |

### 현재 규칙 메모
- **특성 기능은 일시 제외**했습니다. 특성에 의존하던 `조커 ◆A`는 임시로 "매 턴 리롤 +1" 효과로 바꿨습니다.
- AI 난이도는 **쉬움 · 보통 · 어려움** 3단계입니다.
  - 쉬움: 패를 무작위로 고를 때가 있음, 액티브 사용률 낮음
  - 보통: 항상 최적 족보, 액티브 적당히 사용
  - 어려움: 높은 등급 우선 드래프트, 액티브 적극 사용
- 족보 점수와 효과 카드의 N값은 아직 데모용 임시값입니다.
- 덱·대전 기록·설정은 브라우저에 저장됩니다. 설정 → **기록 초기화**로 되돌릴 수 있습니다.
